Sheet Music G2 v1.7.2

Fixes:
- Library is now rendered as simple SDK text containers instead of a native list/image combination, for reliable Simulator and G2 rendering.
- After the startup screen, the library is always shown automatically.
- WETSCHER OPTIK + SHEET MUSIC are rendered directly as text.
- Empty library message: Keine Noten vorhanden. Speichere Noten in der Handy-App ab.
- Swipe changes the selected score, click opens it.
- In score view, swipe changes pages and click returns to the library.
- Double click exits through the required system shutdown flow.
- PDF fixes from v1.7.1 remain included.
- Startup errors are no longer silently swallowed; they are shown in the phone status area.
