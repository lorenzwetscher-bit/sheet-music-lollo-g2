Sheet Music for Even G2 – v1.7.3

Fixes:
- Library redesigned to match the requested Wetscher Optik / SHEET MUSIC layout.
- Uses the supplied Wetscher Optik logo.
- Selected saved score has a visible rounded border.
- Swipe up/down cycles through saved scores.
- Single click reliably opens the selected score.
- Single click in score view reliably returns to the library.
- Fix for CLICK_EVENT value 0 being omitted by protobuf/simulator events.
- Added navigation debounce to prevent double-triggered page changes.
- Staff-line recognition strengthened with a second five-line horizontal detector.
- Recognition now also handles dark-background / bright-notation images by normalizing polarity for detection.
- Existing PDF, photo, HEIC/TIFF, crop, contrast, invert, save and G2 rendering functionality retained.
